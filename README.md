# Мастер Строй — лендинг производителя бетонных изделий

Адаптивный одностраничный сайт производителя тротуарной плитки и бетонных изделий в Волоколамском районе.

## Технологии

- React
- Vite
- Tailwind CSS 4 (подключён через Vite plugin)
- Lucide React
- CSS для точной настройки адаптивного макета

## Запуск локально

Установите Node.js LTS, распакуйте проект и откройте папку `master-stroy` в VS Code.

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite, обычно `http://localhost:5173`.

Проверка production-сборки:

```bash
npm run build
npm run preview
```

## Что есть на странице

- Двухуровневая шапка, фиксируемая навигация и мобильное бургер-меню
- Hero-блок с переходом к каталогу
- Категории продукции
- Блок «О компании»
- Карточки топовых товаров с выбором цвета и характеристиками
- Блок о производстве с видеопревью
- Галерея работ с лайтбоксом и переключением фото клавишами
- Преимущества компании
- Доставка, контактные данные и карта
- Форма обратного звонка с проверкой обязательных полей и маской телефона
- Адаптивность для десктопа, планшета и мобильных устройств

## Архитектура (FSD)

```
src/
├── app-уровень: main.jsx, App.jsx (провайдеры)
├── pages/homepage/     — страница и её секции (Hero, Catalog, About, ...)
├── widgets/            — крупные блоки: Header, Footer, Brand, SectionHeading, TileField
├── features/           — действия пользователя: callback, navigation, products, gallery
├── entities/siteData.js — данные: товары, категории, контакты
└── shared/             — переиспользуемое: hooks (useInView, useCountUp), ui (Reveal), styles
```

Правило: импортировать можно только «вниз»: pages → widgets → features → entities → shared.

## Картинки

Все фото лежат в `src/shared/assets/images/` (hero, factory, truck, а также папки works, categories, products). Подключаются они импортами в начале `src/entities/siteData.js`. Сейчас там заглушки с тем же именем: просто замените файл своим фото. Если у нового фото другое расширение (например, `.png`), поправьте строку import в `siteData.js`.

## Вход и регистрация

- Кнопка «Войти» в шапке открывает окно «Вход / Регистрация». После входа — меню профиля с кнопкой «Выйти»; имя подставляется в форму обратного звонка.
- **Аутентификация** (кто ты): `features/auth/AuthModal.jsx` → `entities/user/api/authApi.js`. Токен хранится в `localStorage`, при обновлении страницы сайт спрашивает сервер `GET /auth/me`.
- **Авторизация** (что тебе можно): компонент `<RequireAuth role="admin">…</RequireAuth>` показывает содержимое только нужной роли.
- По умолчанию работает **демо-сервер в браузере** (`mockAuthApi.js`). Тестовый админ: `admin@master-stroy.ru` / `admin123`.
- Чтобы подключить настоящий бэкенд, создайте файл `.env` (пример — `.env.example`) с `VITE_API_URL=http://localhost:3000`. Бэкенд должен отвечать на `POST /auth/register`, `POST /auth/login`, `GET /auth/me` (контракт — в `authApi.js`).

## Анимации

- hero: плитка «укладывается» рядами, строки заголовка выезжают, счётчики считают, фон двигается с параллаксом
- при прокрутке: блоки появляются (`Reveal`), фото раскрываются «шторкой»
- шапка: подсветка текущего раздела, полоса прогресса, кнопка «Наверх»
- преимущества: оранжевая заливка при наведении; доставка: едет грузовик; видео: пульсирующая кнопка
- `prefers-reduced-motion` отключает движение

## Что заменить перед публикацией

Данные в проекте демонстрационные. Перед публикацией замените:
1. Номера телефонов, email и точный адрес в `src/entities/siteData.js`.
2. Ориентировочные цены, размеры и характеристики товаров.
3. Фотографии Unsplash на реальные фотографии продукции, производства и объектов.
4. Превью видео на ссылку на настоящее видео компании.
5. Координаты карты на точный адрес производства.

Форма обратного звонка сейчас демонстрирует интерфейс и состояние успешной отправки. Для реального получения заявок подключите backend, CRM или сервис форм.
